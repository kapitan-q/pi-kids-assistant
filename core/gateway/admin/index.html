Профили колонки

Новый профиль появляется, когда человек скажет колонке «давай познакомимся». Здесь назначаются роль и ограничения.

Загружаю…

Роли и режимы описаны в config/speaker.yaml. Личные ограничения только сужают роль. «Объединить» переносит записанный голос в другой профиль (например, в «Старший»), чтобы правила расписания для него продолжили работать.
